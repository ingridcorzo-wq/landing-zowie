# Landing – Curso de Componente Docente

Página de inscripción del **Curso de Componente Docente** del Centro de Capacitación Docente Zowie.

- Sitio oficial: https://www.centrodocentezowie.com/
- Instagram: [@ccptzowie](https://www.instagram.com/ccptzowie/)

## Estructura

Todo el sitio vive en un único archivo, `index.html` (estilos, logotipo y scripts incluidos), por lo que se puede publicar en cualquier hosting estático sin compilar nada.

## Publicar con GitHub Pages

1. En el repositorio, ir a **Settings → Pages**.
2. En *Build and deployment*, elegir **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
3. Guardar. A los pocos minutos la página queda disponible en
   `https://ingridcorzo-wq.github.io/landing-zowie/`.
